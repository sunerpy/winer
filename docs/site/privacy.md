# 数据与隐私

winer 没有账号，不收集使用数据，也没有自己的服务器。它只会连接下面这些地址：

| 连接                 | 发送什么                   | 用来做什么                                          |
| -------------------- | -------------------------- | --------------------------------------------------- |
| 本机的英雄联盟客户端 | 客户端自己生成的本地凭证   | 读取召唤师、对局和战绩，执行自动化操作              |
| 所在大区的战绩服务器 | 客户端登录时拿到的访问令牌 | 分页读取战绩，地址形如 `nj100-sgp.lol.qq.com`       |
| ARAM.GG              | 一次普通的网页请求         | 获取海克斯符文的效果说明；可在 **设置 › 通用** 关闭 |
| GitHub               | 一次普通的网页请求         | 检查更新、下载更新包                                |

客户端的凭证和访问令牌只在内存里使用，不写入设置文件，也不写进日志。

## 保存在本机的数据

| 内容 | 位置                                        |
| ---- | ------------------------------------------- |
| 设置 | `%APPDATA%\app.winer.desktop\settings.json` |
| 日志 | `%LOCALAPPDATA%\app.winer.desktop\logs`     |

## 客户端插件

插件运行在客户端的界面页面里，只连接本机上 winer 打开的端口，凭 winer 交给它的令牌通信，不访问任何外部地址。

## 文档站

文档站 firlab.app 是静态页面，由 GitHub Pages 托管；winer 在浏览器里打开它，本身不向它发送任何数据。
