# 客户端增强

客户端插件把 winer 的一部分功能放进英雄联盟客户端的界面里。它经由
[Pengu Loader](https://github.com/PenguLoader/PenguLoader)（一个给客户端界面加载插件的开源工具）加载，winer
自带了它，不需要另外安装。

## 自动安装

winer 第一次连上客户端时会自动完成这些事：

1. 把自带的 Pengu Loader 放进 winer 自己的数据目录，并在客户端目录里创建 `version.dll` 链接来激活它，和 Pengu Loader
   自己的激活方式相同。Windows 只允许管理员创建这种链接，所以第一次激活需要一次管理员权限，见下一节。
2. 装好 winer 的插件，以后随 winer 一起更新。
3. 客户端空闲（不在房间、排队、选人或游戏中）时重载一次客户端界面，让插件立即生效；不空闲时，下次打开客户端生效。
   重载只重启客户端的界面进程，不影响登录。

Pengu Loader 自己的欢迎窗口和启动提示不会出现。已经装过 Pengu Loader 的，winer 继续使用你原来的那个，只装插件。
客户端目录里已有别的 `version.dll` 时，winer 不会改动它，**客户端增强** 页会说明原因。

## 第一次激活需要管理员权限

激活 Pengu Loader 要在客户端目录里创建一个链接，而 Windows 只允许以管理员身份运行的程序创建这种链接。所以第一次
激活时，如果 winer 不是以管理员身份运行的，它会自动请求以管理员身份重启：在 Windows 的用户账户控制提示里选
**是**，winer 重启并再次连上客户端后就会完成激活。

如果选了 **否**，**客户端增强** 页会说明需要管理员权限，点 **以管理员身份重启** 可以再试一次。链接建好以后，
winer 以普通权限运行也能继续使用它，不会再次请求。

客户端本身以管理员身份运行时（国服客户端由 WeGame 启动时就是这样），winer 为了连接客户端已经请求过管理员权限，
激活时不会再提示。

## 客户端里能看到什么

- **选人阶段队友面板**：在选人界面每位队友的名字下方加一行：档位与称号、段位、近期胜率、KDA 和连胜连败，你自己
  那一行还会标出所在的红蓝方。找不到客户端的队伍栏时，改为显示一个紧凑的面板。点这一行或面板里的队友可以查看他的
  战绩，见下面的 **在客户端里查看战绩**。
- **在客户端里秒换备选席英雄**：大乱斗里直接点客户端备选席上的英雄就能换过来，不用等它的冷却。
- **好友列表里的游戏状态**：客户端右侧的好友列表里，游戏中的好友名字下方多一行模式和已进行的时间，每秒更新；
  在同一局游戏或同一个队伍里的好友，左边带同一种颜色的竖条。
- **房间里的队友战绩**：组队房间里每位成员的横幅上方显示近期胜率、KDA 和战力分。点这一行或成员的头像可以查看
  他的战绩，见下面的 **在客户端里查看战绩**。找不到客户端的成员卡片时，改为显示一个紧凑的面板，点面板里的成员也
  一样。
- **在客户端里查看战绩**：在组队房间或选人界面点一名玩家时，客户端里会在他旁边弹出一张卡片，不用切换到 winer 的
  窗口。卡片上方是他的段位、近期胜率、KDA、战力分和连胜连败（选人时还有档位和称号），下方是最近 10 局对局
  （战绩页隐藏自定义对局时，这里也不列出），每局列出英雄、胜负、模式、击杀 / 死亡 / 助攻和距今多久；读取失败时
  卡片说明原因，可以点 **重试**。点卡片底部的 **在 winer 中查看完整战绩** 会打开 winer 的窗口。按 `Esc`、点卡片
  右上角的 ✕ 或再点一次同一名玩家可以关闭卡片；离开房间或选人界面、出现接受对局的提示时，卡片自动关闭。关闭这个
  选项后，点玩家改为直接在 winer 的窗口里打开他的战绩。
- **隐藏首页推广**：隐藏赛事弹窗，并把客户端首页的资讯和活动换成一张说明卡片。点卡片上的 **暂时显示**
  可以恢复显示，客户端重启后再次隐藏；关闭这个选项后，首页一直照常显示。

每一项都在 **客户端增强 › 客户端内功能** 里单独开关，改动立即生效。

## 插件需要 winer 在运行

插件的数据来自 winer：它只连接本机上 winer 打开的端口，并凭 winer 交给它的令牌通信。winer 没有运行时，插件什么都
不显示，也不影响客户端本身。

## 停用

在 **客户端增强** 页点 **停用客户端增强**：winer 移除插件，并删除它自己创建的 `version.dll` 链接（你自己安装的
Pengu Loader 保持不变），客户端下次启动后生效。点 **启用客户端增强** 可以重新打开。
