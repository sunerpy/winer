# 战绩与成就

## 查谁的战绩

**战绩** 页默认是你自己的战绩。在搜索框输入 `名称#编号`（例如 `暗夜里的光#10003`）可以查任何人；在对局分析
或记分板里点玩家的名字，也会打开他的战绩。

## 玩家资料

页面顶部是这位玩家的资料：单双排和灵活组排的段位、近期战绩，以及近期战力的档位。

- **近期战绩**写作「近 18 场 · 所有模式」：数的是客户端列出的最近对局里最新的 20 场，各种模式都算，不只是
  排位。自定义对局和人机对局（包括新手教程）不计入，也不占这 20 场；重开局只在色条里显示为灰色，不计入胜负、
  KDA 和连胜。旁边的问号写出这一次的具体情况：客户端列出了几场、计入的对局按模式各有几场、跳过了几场自定义和
  人机对局。
- **近期战力**显示和选人时一样的档位、毒舌称号和评语。只看一位玩家时没有队友可比，档位按固定分段换算，问号里
  写着换算的过程，规则见[评级说明](/rating#只看一位玩家时)。

概览页的「近期状态」用的是同一组数字，标题同样写明「近 N 场 · 所有模式」；段位卡片里的胜负场次是排位赛的，
和近期战绩不是一回事。

## 翻页与筛选

战绩按页显示，每页 10、15、25 或 50 场，选择会被记住。上方可以按 **全部、排位、匹配、大乱斗、其他** 筛选，
筛选后每一页仍然是满的。

旁边的 **隐藏自定义对局** 默认打开：自定义对局（包括训练模式）不出现在战绩列表和概览的最近对局里，开关旁会
写出隐藏了几场。关掉后自定义对局照常显示，选择会被记住。无论开关如何，自定义对局都不计入近期战绩和战力。

腾讯客户端自己的战绩接口只给最近 20 场。winer 用客户端的登录凭证向所在大区的战绩服务器分页查询，所以能翻完
整个历史；连不上战绩服务器时退回客户端的 20 场，并在列表下方说明。

刚看过的战绩会暂存一段时间：回到刚看过的玩家时，资料和列表立即显示，停在离开时的那一页，同时在后台确认有没有
新对局；看过的记分板再次点开时不再重新读取。最新一页战绩最多暂存一分半钟，自己打完一局后再打开会重新读取；
切换账号后，暂存的内容全部清空。

## 每一局

列表里的每一局显示胜负、队列、时间、时长、击杀/死亡/助攻、补刀和伤害、召唤师技能与符文（海克斯大乱斗和斗魂
竞技场显示海克斯符文），以及装备。

- **MVP / SVP**：标在英雄头像的左上角。MVP 是胜方评分最高的人，SVP 是败方评分最高的人。
- **成就徽章**：头像右侧的时间后面最多显示 3 个本局成就，其余收在「+N」里，鼠标停上去可以看到全部。

| 徽章                   | 什么时候出现                 |
| ---------------------- | ---------------------------- |
| 双杀、三杀、四杀、五杀 | 本局最多的一次多杀           |
| 超神                   | 连续击杀 8 人以上没有阵亡    |
| 一血                   | 拿下本局第一个击杀           |
| 杀人最多、助攻最多     | 全场击杀、助攻最多           |
| 输出最高、承伤最高     | 全场对英雄伤害、承受伤害最多 |
| 金币最多、补兵最多     | 全场经济、补刀（含野怪）最多 |
| 推塔最多               | 全场推掉的防御塔最多         |
| 逃兵                   | 本局被系统判定挂机或提前离开 |

多杀按等级换颜色，五杀和超神带一圈描边；各项最多用记分板的琥珀色；逃兵用红色。完整规则见[评级说明](/rating#成就徽章)。

## 记分板

点开一局就是这局的记分板，两队各一张表：

- 每位玩家的英雄、召唤师技能、名称、MVP/SVP，名称下方是海克斯符文、成就小图标和单局称号。
- 击杀/死亡/助攻与 KDA，**评分**（0–10）和下方的单局评级（S+ 到 F），伤害与伤害占比，承伤，参团率，经济，
  补刀，装备。
- 全场伤害、承伤、经济最高，死亡最少和评分最高的数值用琥珀色标出。
- 你正在查看的玩家所在行带强调色底。

评分、评级和称号的算法见[评级说明](/rating)。单局称号可以在 **设置 › 评级** 里关掉。
