# 自动化

**自动化** 页里的每一项都默认关闭，打开后才会替你操作。每一项下方的 **适用模式** 决定它在哪些模式里生效：
排位、匹配、极地大乱斗、海克斯大乱斗、斗魂竞技场和其他模式。只列出这一项用得上的模式，例如大乱斗没有选英雄
和禁英雄的阶段，备选席只有大乱斗才有。

页面顶部的 **按模式查看** 选中一个模式后，只显示那个模式里用得上的项目，并用一句话说明在那里实际会发生什么。
概览页的自动化开关下方也会写出各自的模式。

## 匹配成功

- **自动接受对局**：匹配成功后自动点接受。**接受前等待** 可以留出几秒，让你有机会自己拒绝。

## 英雄选择与禁用

- **自动选择英雄**：轮到你时，按 **英雄顺序** 选第一个能选的英雄。顺序分「通用」和五个分路，分到某个分路时
  先看那个分路的列表，再看通用列表。已被禁用、已被锁定、队友已经选中或亮出意向的英雄，以及你没有的英雄，
  都会被跳过。你自己已经预选了英雄时，用的是你预选的那个。
- **选择方式**：**直接锁定** 选好就锁定；**仅预选** 只把英雄放上去一次，之后由你自己决定。
- **规划阶段亮出意向**：在规划阶段先把要选的英雄亮给队友看。
- **自动禁用英雄**：轮到你禁用时，按禁用列表禁掉第一个可禁的英雄；队友已经选中或亮出意向的英雄不会被禁。
  你已经点了一个要禁的英雄时，禁的是你点的那个。

## 战力喊话

- **进入选人后自动发送**：队友战绩读完后自动发送[对局分析](/guide/live#战力喊话)里的那段喊话。
- **发送给**：队伍聊天，或者仅自己可见。
- **包含自己**：喊话里是否带上你自己那一行。
- **评级方案**：档位名称来自 **设置 › 评级**，点 **去设置** 可以直接过去。
- **开场白** 与 **每行内容**：第一行总是红蓝方和「winer 战绩鉴定」，开场白接在后面，留空时不加；每行内容可用这些占位符：
  `{standing}` 档位、`{seat}` 位置（选人界面我方列表里从上往下数，1L 到 5L）、`{name}` 名称、`{champion}` 英雄、
  `{games}` 场次、`{winRate}` 胜率、`{kda}`、`{score}` 近期战力、`{title}` 称号、`{quip}` 评语。留空使用默认格式，
  它写位置和名称，不写选人时还会变的英雄；修改时下方有实时预览。

## 对局结束

- **自动返回房间**：对局结束后自动回到房间，方便继续排下一局。

## 备选席

- **自动换心愿英雄**：极地大乱斗和海克斯大乱斗里，备选席出现比你手上更靠前的心愿英雄时立刻换过来，不等冷却。
  **心愿英雄** 最多 20 个，越靠前越优先；手上的英雄不在名单里时，名单上的都算更好。
