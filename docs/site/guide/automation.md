# 自动化

**自动化** 页里的每一项都默认关闭，打开后才会替你操作。每一项下方的 **适用模式** 决定它在哪些模式里生效：
排位、匹配、极地大乱斗、海克斯大乱斗、斗魂竞技场和其他模式。只列出这一项用得上的模式，例如大乱斗没有选英雄
和禁英雄的阶段，备选席只有大乱斗才有。

页面顶部的 **按模式查看** 选中一个模式后，只显示那个模式里用得上的项目，并用一句话说明在那里实际会发生什么。
概览页的自动化开关下方也会写出各自的模式。

## 匹配成功

- **自动接受对局**：匹配成功后自动点接受。**接受前等待** 可以留出几秒，让你有机会自己拒绝。

## 英雄选择与禁用

- **自动选择英雄**：轮到你时，按 **英雄顺序** 选第一个能选的英雄。顺序分「通用」和五个分路，分到某个分路时
  先看那个分路的列表，再看通用列表。已被禁用、已被锁定、队友已经选中或亮出意向的英雄，以及你没有的英雄，
  都会被跳过。你自己已经预选了英雄时，用的是你预选的那个。
- **选择方式**：**直接锁定** 选好就锁定；**仅预选** 只把英雄放上去一次，之后由你自己决定。
- **规划阶段亮出意向**：在规划阶段先把要选的英雄亮给队友看。
- **补位时只用该分路的列表**：默认打开。被分到房间里没选的分路时（补位），只从这个分路自己的列表里选，不用通用
  列表；这个分路没有列表就不自动选。房间里选了 FILL、没选分路，或者没有分路的模式，都不算补位。你自己预选的英雄
  照常锁定。英雄选择里你的座位会标出「补位」。
- **自动禁用英雄**：轮到你禁用时，按禁用列表禁掉第一个可禁的英雄；队友已经选中或亮出意向的英雄不会被禁。
  你已经点了一个要禁的英雄时，禁的是你点的那个。

## 符文与召唤师技能

- **自动配置符文和召唤师技能**：锁定英雄后，换上你上一局用这个英雄在这个模式里的符文和召唤师技能。极地大乱斗和
  海克斯大乱斗没有锁定这一步，每换一次英雄（从备选席换、重随）就换一次。一次英雄选择里每个英雄只换一次，之后你自己的
  改动不会被覆盖；换走再换回来时会重新换上。斗魂竞技场没有符文页，召唤师技能也是固定的，所以不在适用模式里。
- **记住什么**：每局游戏开始时，记下你最终带进游戏的符文页和两个召唤师技能，按英雄和模式分开保存，排位和匹配也分开；
  哪怕你一点都没改，也会记下。只保存在这台电脑上。
- **没有记录时用客户端推荐**（默认打开）：这个英雄在这个模式里尚无记录时，改用客户端自己推荐的符文页和召唤师技能。
  召唤师峡谷按分到的位置推荐，两种大乱斗不分位置。
- **符文页**：winer 只用一页符文页，名为「winer · 英雄名」，每次都改这一页。尚未建立这一页时，有空位就新建一页；没有
  空位时只会写入客户端为当前英雄生成的临时页，不会改你自己的符文页。哪里都写不了时，召唤师技能照常更换，并在动态里
  说明符文没有改动的原因。
- **召唤师技能**：你本来就带着的技能留在原来的按键上，例如闪现原来在 F 键，换完还在 F 键。
- **已记住 N 套** 与 **清除记忆**：显示一共记住了多少套，清除后全部忘掉。

每次替你换完，概览页的 **动态** 里都会记一条，例如「为 戏命师 应用了记住的符文和召唤师技能」；失败时写明原因。
不会往聊天里发任何内容。

## 装备方案

- **自动写入装备方案**（实验性）：锁定英雄后，把对局页[配装推荐](/guide/live#配装推荐)里的出装写成这个英雄的装备方案，
  分为起始装备、鞋子、核心装备和后期可选四组，组名带上数据来源和版本。默认关闭，暂不推荐使用，仍在试验中：选人时写入的
  方案本局就在游戏内商店里，游戏开始后再写入的要到下一局。
- 每个英雄在每张地图上只保留一个 winer 的方案，名为「winer · 英雄名」：排位和匹配都在召唤师峡谷，两种大乱斗都在
  嚎哭深渊。你自己的装备方案原样保留。
- 需要先在 **设置 › 通用** 打开 **配装推荐**。
- **清除 winer 装备方案**：删掉 winer 写入的全部方案，也只删这些。

## 战力喊话

- **进入选人后自动发送**：队友战绩读完后自动发送[对局分析](/guide/live#战力喊话)里的那段喊话。
- **发送给**：队伍聊天，或者仅自己可见。
- **包含自己**：喊话里是否带上你自己那一行。
- **喊话样式**：中文默认参考 Sona，按「位置、档位、胜率、KDA、战力」排列；**丰富**（默认）再加档位表情和统计场次，
  **精简** 去掉这两项。默认不带玩家名、称号和评语，避免自由文本被聊天过滤器连读；这些仍在窗口和客户端增强面板显示。
  表情只在客户端的聊天里显示，游戏里输入的喊话不带表情。
- **评级方案**：档位名称来自 **设置 › 评级**，点 **去设置** 可以直接过去。
- **开场白** 与 **每行内容**：第一行总是红蓝方和「winer 战绩鉴定」，开场白放在【】里接在后面，留空时不加；
  每行内容可用这些占位符：`{emoji}` 档位表情、`{standing}` 档位、`{seat}` 位置（选人界面我方列表里从上往下数，
  1L 到 5L）、`{name}` 名称、`{champion}` 英雄、`{games}` 场次、`{winRate}` 胜率、`{kda}`、`{score}` 近期战力、
  `{title}` 称号、`{quip}` 评语。留空使用所选样式的 Sona 式安全格式：写位置和统计列，不写选人时还会变的英雄，也不写
  玩家名、称号或评语（见[评级说明](/rating#喊话)）。自己写模板时所有占位符仍可用，但自由文本可能被客户端过滤。
  修改时下方有实时预览。
- **发送喊话的快捷键**：默认不设置。设置后，英雄选择中按下它，喊话发到队伍聊天，和对局页的 **发送到队伍** 相同；游戏中
  打开了 **游戏内发送** 时，按下它把下面选定的游戏中喊话输入游戏的队伍聊天。winer 的窗口隐藏时也有效，结果记在概览页的
  **动态** 里。组合键的设置方法和唤起 winer 的快捷键相同（见[设置](/guide/settings)），两个快捷键不能用同一个组合键。

### 游戏中的喊话

游戏里的聊天没有客户端接口，只能像玩家一样打字。打开 **游戏内发送**（默认关闭）后，在游戏中按下发送喊话的快捷键，
winer 会模拟键盘：按 `Enter` 打开队伍聊天，输入一行，再按 `Enter` 发送，逐行进行，一行太长时分成几条。

- 只在游戏窗口已经在前台时输入，winer 不会把游戏切到前台。输入时游戏窗口一离开前台就停止，已经输入一半的文字留在游戏的
  聊天框里，不会发出去。
- 先等所有按键松开再开始输入：按住 `Shift` 时的 `Enter` 会打开所有人可见的聊天，一直按住的键会重复输入。
- 按快捷键前先关上聊天框：聊天框开着时，第一次 `Enter` 会把框里已有的文字发出去。
- 输入要几秒钟，这期间你按下的键会混进正在输入的那一行。
- 游戏以管理员身份运行时，winer 也要以管理员身份运行才能向它输入，Windows 不允许权限较低的程序向权限较高的窗口模拟按键。
  客户端以管理员身份运行时，winer 连接它时本来就会请求以管理员身份重启。
- 向游戏模拟按键属于第三方输入，可能违反游戏的服务条款，使用风险由你自行承担。

**游戏中输入哪一方** 决定按一次快捷键输入什么：

- **对面**（默认）：提防的敌人和可以针对的敌人，最多 3 行。队友在选人时已经听过自己的情况，而每多输入一行，你就要
  多等一会儿。
- **我方**：每位队友一行，和选人时一样从好到差排列，**包含自己** 同样适用。
- **双方**：先输入对面，再输入我方。

每输入一行要占用键盘一秒左右，所以每按一次最多输入 6 行：我方的第一行加 5 位队友正好输入完；选双方时，超出的我方
队友（档位最低的几位）不输入。

两位敌人这样选出：

- **提防的敌人**：评级高于中游的敌人里最高的一位。
- **可以针对的敌人**：评级低于中游的敌人里最低的一位。

按本队排名的方案以中间一档为中游，例如峡谷五档的前两档高于中游、后两档低于中游；峡谷八档以 B、C 两档为中游。没有这样
的敌人时那一行不发，两行都没有时对面什么都不发。战绩隐藏、读取失败或没有对局的玩家不参与。斗魂竞技场这类没有红蓝方的
模式没有游戏中的喊话。

进入游戏后英雄已经定下，大家也习惯按英雄认人，所以默认格式只写英雄，放在【】里，不写名称和位置；读不到英雄时改用
名称。三种行的格式都可以修改（**提防的敌人**、**可以针对的敌人** 和 **我方每行**），占位符与每行内容相同；
`{champion}` 是这位玩家正在玩的英雄，`{seat}` 是他在本队列表里的位置。选双方时，按一次输入的内容例如：

```text
【敌方·红色方】winer 战绩鉴定
小心【卡兹克】：峡谷通天代，近20场胜率65%，KDA 4.6
对面【亚索】：纯正牛马，近20场胜率35%，可以多抓
【我方·蓝色方】winer 战绩鉴定
【阿狸】|档位峡谷通天代|近20场胜率60%|KDA4.1|战力7.4
人形防御塔【李青】，近20场胜率55%，KDA 3.6，战力6.8【靠谱队友】，塔在人在，人在塔也在
```

选了精简样式时，我方每行写成「人形防御塔【李青】｜胜率55%｜KDA 3.6｜战力6.8」。

修改时下方有实时预览，用你自己的近期战绩演示按一次快捷键会输入的内容。

## 对局结束

- **自动返回房间**：对局结束后自动回到房间，方便继续排下一局。

## 备选席

- **自动换心愿英雄**：极地大乱斗和海克斯大乱斗里，备选席出现比你手上更靠前的心愿英雄时立刻换过来，不等冷却。
  **心愿英雄** 最多 20 个，越靠前越优先；手上的英雄不在名单里时，名单上的都算更好。
