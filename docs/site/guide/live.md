# 对局分析与喊话

**对局** 页在组队房间里列出房间成员，在英雄选择和游戏进行中显示双方玩家的分析和你这个英雄的[配装推荐](#配装推荐)，客户端回到首页后清空，只留下查看英雄配装的面板。

## 对局分析

每位玩家占一行：

- **左侧**：英雄、名称、档位与称号、段位、近期胜率、KDA 和连胜连败。档位下方是这一档的毒舌评语。战绩被
  隐藏的玩家只显示「隐藏的玩家」，不参与评档。
- **右侧**：最近 6 到 12 局（窗口越宽显示越多），每局一格：英雄、击杀/死亡/助攻、模式，胜利是绿色，失败是红色，
  重开是灰色。鼠标停在格子上会显示队列、结果和时间。某位玩家的战绩读取失败时，这里显示 **重试**，点一下重新读取；
  在选人和房间里，不点的话 winer 半分钟后也会自己再读。战绩服务器繁忙时（多在晚上），整页的战绩会超时，winer 改为
  一场一场地同时读每位玩家最近的 20 场，档位会晚十几秒出来；个别对局读不到时，默认喊话里的「近 N 场」照实写出场次。

点玩家的名字会打开他的战绩。我方和敌方都能看到时，标题右侧可以在两队之间切换。

- **红蓝方**：召唤师峡谷、嚎哭深渊等分红蓝方的地图，标题会写明我方是哪一方，喊话的第一行也会带上
  「【蓝色方】」或「【红色方】」。斗魂竞技场没有红蓝方。
- **开黑**：游戏开始后，同一组开黑的玩家带相同的编号（「开黑 1」「开黑 2」），每组一种颜色；编号始终显示，
  分不清颜色也不影响。英雄选择阶段，和你从同一个房间进来的队友也会标出来。其他队友如果最近一起同队打过至少 2 局，
  其中至少 1 局在两人各自最近的 10 局里，会标成「疑似开黑」，色块是虚线框：这是根据战绩推断的，可能不准。只有腾讯大区
  的战绩里有每局的十名玩家，其他大区不做推断。
- **档位**：按近期战力评出，方案在 **设置 › 评级** 里选，规则见[评级说明](/rating)。

## 组队房间

在组队房间里（排队和确认对局时也一样），**对局** 页列出房间里的每位成员：名称、想打的位置、段位、近 20 场的胜率和
KDA、近期战力分和最近的对局，房主带 **房主** 标记。点成员打开他的完整战绩。自定义房间里的所有人都会列出来。

## 好友动态

**概览** 页的 **好友动态** 列出正在英雄选择或游戏中的好友：模式、状态和已进行的时间，时间每秒更新，可以观战的
对局带一个眼睛图标。在同一局游戏或同一个队伍里的好友带同一种颜色和编号。点好友打开他的战绩。

## 战力喊话

喊话内容在队友的战绩全部读完后生成：第一行是红蓝方、「winer 战绩鉴定」和开场白（如果填了），之后每位队友一行，
按选人列表的 1L 到 5L 排列，不再按档位高低重排。中文默认按「位置、档位、胜率、KDA、战力」阅读；选人列表的 1L 到 5L 已能识别玩家，因此
不带容易被过滤器连读的玩家名、称号和评语。整段喊话作为一条消息发出；如果队伍聊天里的喊话发出后又消失，可以在 **自动化 › 战力喊话 › 发送方式** 改为每行一条，每行之间留出间隔（见[评级说明](/rating#喊话)）。例如：

```text
📢【蓝色方】winer 战绩鉴定
1L: 👑 峡谷通天代|近20场胜率60%|KDA4.1|战力7.4
```

在 **自动化 › 战力喊话** 把 **喊话样式** 改成精简后，每人一行，几项按同样的顺序排好，方便对比：

```text
【蓝色方】winer 战绩鉴定
1L: 峡谷通天代|胜率60%|KDA4.1|战力7.4
```

- **发送到队伍**：发到选人阶段的队伍聊天，队友都能看到。
- **仅自己可见**：只显示在你自己的聊天框里，适合先看一眼。
- **自动发送**：在 **自动化 › 战力喊话** 打开 **进入选人后自动发送**，并选择发送给谁、是否包含自己。开场白和
  每行的格式也在那里修改，修改时有实时预览。
- **快捷键**：在 **自动化 › 战力喊话** 设置发送喊话的快捷键后，选人时按下它和点 **发送到队伍** 相同，不必打开 winer 的
  窗口。面板底部写着当前的快捷键，没有设置时说明去哪里设置。

游戏开始后，面板分成两栏：**对面** 是最该提防的一位和最好针对的一位，这两位怎样选出见
[自动化](/guide/automation#游戏中的喊话)；**我方** 和选人时一样，每位队友一行，保持队伍列表顺序。进入游戏后英雄已经定下，
大家也习惯按英雄认人，所以两栏都用英雄称呼玩家，放在【】里，不写名称和位置；读不到英雄时改用名称。例如：

```text
【敌方·红色方】winer 战绩鉴定
小心【卡兹克】：峡谷通天代，近20场胜率65%，KDA 4.6
对面【亚索】：纯正牛马，近20场胜率35%，可以多抓
```

游戏里的聊天没有接口，所以这时面板里没有发送按钮：打开 **游戏内发送** 后，在游戏里按发送喊话的快捷键，winer 把
选定的内容输入队伍聊天，默认是对面这一栏，可以在 **自动化 › 战力喊话** 改成我方或双方。面板标题右侧写着游戏内发送
是否开启，底部写着快捷键和按下后输入的内容。斗魂竞技场这类没有红蓝方的模式没有游戏中的喊话，也不显示这个面板。
从 WeGame 启动的游戏以管理员身份运行，winer 也要以管理员身份运行才能向它输入，见[游戏中的喊话](/guide/automation#游戏中的喊话)。

## 反击

侧栏的 **反击** 页（`Ctrl` + `7`）管理按快捷键发出的反击语句。语句由你自己写，winer 不自带任何语句；也可以下载
开源的在线语录，见下文。

- **反击语句**：每行一句，最多 100 句，每句最多 200 字。按一次快捷键随机发一句，不会连着两次发同一句。
- **快捷键**：**发到队伍** 和 **发到全体** 各一个，默认都不设置，不能和唤起 winer、发送喊话、**发给交换的队友** 的快捷键相同。英雄选择中，
  两个都发到选人聊天，只有队友能看到；游戏中打开 **在游戏里输入** 后，**发到队伍** 输入队伍聊天，**发到全体** 在语句前
  加上 `/all ` 输入所有人可见的聊天，一句太长时分成几条。winer 的窗口隐藏时也有效，结果记在概览页的 **动态** 里：
  全部发出、只发出一部分，或者没有发出以及原因。没有可发的语句（没写语句，也没打开在线语录）时，这里有一行提示。
- 两次发送之间至少隔 3 秒，以免刷屏被举报。
- **游戏内发送**：其中的 **在游戏里输入** 默认关闭。打开后，游戏中按快捷键时 winer 模拟键盘输入，规则和[游戏中的喊话](/guide/automation#游戏中的喊话)
  相同。winer 没有以管理员身份运行时，这里会提示从 WeGame 启动的游戏收不到它的按键，并提供 **以管理员身份重启**。

在游戏里辱骂其他玩家可能被举报，导致禁言甚至封号。winer 只替你发出你自己选定的内容，后果由你承担。

### 选人快捷语

英雄选择中，对局页上每位队友（不含你自己）旁边有一个快捷语菜单，点其中一句就把它发到选人聊天，楼层和英雄会自动填好。
例如想请 5 楼让出英雄时：

```text
5L大佬，小弟想玩下龙王，给您磕一个了
```

快捷语在 **反击 › 选人快捷语** 里编辑，最多 20 句，每句最多 200 字，可用 `{seat}` 楼层（1L 到 5L）、`{champion}`
这位队友的英雄和 `{name}` 名称；名称被隐藏时为空，连同它外面的括号一起去掉。全部删除后恢复默认的那一句。发送前 winer
会核对仍是同一局英雄选择、对方是你的队友，菜单留到下一局也不会发错人。

同一栏里的 **发给交换的队友** 是快捷语的快捷键，默认不设置。英雄选择中，先在客户端里对想换英雄的队友点「交换」，再按下它，
winer 就把第一句快捷语发到选人聊天，楼层和英雄填成那位队友的，不必打开 winer 的窗口。没有发起交换、对方已经回应，或
离上一句不到 3 秒时不发送，原因记在概览页的 **动态** 里。它不能和唤起 winer、发送喊话和反击的快捷键相同。

### 在线语录

**反击 › 在线语录** 可以下载开源项目[祖安语录](https://github.com/cndiandian/zuanbot.com)（Apache-2.0 许可）的词库：
清理后共 1676 句，分 **口吐芬芳**（682 句）和 **火力全开**（994 句）两档。这些语句粗俗，会冒犯他人，发出后可能被举报、
禁言或封号；winer 不编写，也不审核它们。

- 只有点 **下载**、并在确认框里点 **我已了解，下载** 后才会下载。winer 不会自行下载，安装包里也不附带。
- 下载的文件必须和 winer 认得的那一份完全一致（按 SHA-256 校验），否则不保存。先从 jsDelivr 的镜像下载，都失败时再从
  GitHub 下载，按系统代理设置连接。
- 下载完成后 **使用在线语录** 仍然关闭，需要你自己打开，并选择用哪一档或两档都用。打开后，按快捷键时从你自己的语句和
  这些语句里随机抽一句。每次重新下载后都要再打开一次。
- **移除** 删除下载的语录，同时关闭 **使用在线语录**。

## 大乱斗的备选席

极地大乱斗和海克斯大乱斗里，页面顶部会列出备选席上的英雄：点一下立刻换成那个英雄，不用等客户端的冷却。
还有重随次数时，右侧会有 **重随** 按钮。在 **自动化 › 备选席** 里设好心愿英雄后，备选席出现比手上更靠前的
心愿英雄时会自动换过来；心愿英雄在列表里带一颗星。

## 选人推荐

召唤师峡谷的排位和匹配选人时，分到分路、尚未锁定英雄时，队伍上方会推荐 3 个英雄，每个附上理由：

- **克制 / 被克制**：对面已经锁定的英雄出现在这个英雄所在分路的对位数据里时，写出它对那个英雄的胜率。
- **版本 T1–T5**：数据源给出的强度档位（OP.GG 有，腾讯 101 没有）。
- **你在这个分路的战绩**：你最近在这个分路用它打了几场、赢了几场；只有腾讯大区的战绩带分路信息。
- **在你的自选列表中**：它在 **自动化 › 自动选择英雄** 的列表里。

候选来自你给这个分路设的自选列表（再加通用列表），以及你在这个分路玩得最多的 5 个英雄，已被禁用、已被锁定、队友已选
或亮出意向的英雄不会出现。推荐只是展示，winer 不会替你预选或锁定。在 **设置 › 通用** 关掉 **选人推荐** 后不再显示。

## 配装推荐

英雄选择中，对局分析下方是你预选或锁定的英雄的配装推荐；游戏进行中切到 winer，看到的是你正在玩的英雄。没有对局时，
在页面下方选一个英雄和模式也能查看。面板分为几页：

- **出装**：起始装备、鞋子、核心装备（三件一组）和后期可选的单件装备，每一项都标出选用率和胜率。
- **符文**：最常用的几套符文页及其选用率、胜率和场次。**应用符文** 把这一套写入 winer 的符文页并设为当前页，规则见
  [自动化](/guide/automation#符文与召唤师技能)。
- **召唤师技能**：常用的组合。英雄选择中点 **应用召唤师技能** 直接换上，你本来就带着的技能留在原来的按键上。
- **技能加点**：主升顺序和前 15 级的加点。
- **对位**（召唤师峡谷）：这个英雄赢得最多和输得最多的对手，胜率是这个英雄对上他们时的胜率。
- **强化符文**（斗魂竞技场、海克斯大乱斗）：按棱彩、黄金、白银分组，从强到弱排列，可以按名称筛选。海克斯大乱斗标出
  强度档位（S 到 C），斗魂竞技场标出平均名次和拿到第一名的比例，因为那里不论胜负。效果说明来自 ARAM.GG（在
  **设置 › 通用** 可以关闭）。强化符文是在游戏里选的，所以游戏进行中这一页默认打开。

某一页没有数据时不会出现，例如海克斯大乱斗没有符文和召唤师技能的统计。召唤师峡谷可以在面板右侧切换分路；没有分到
位置时（自选模式、手动查看），先显示这个英雄去得最多的分路。

### 数据来源

面板标题右侧写着数据来源和版本，例如「数据：腾讯 101 · 16.19」，以及统计的场次。

| 模式         | 数据来源                                                          |
| ------------ | ----------------------------------------------------------------- |
| 排位、匹配   | 腾讯掌上英雄联盟的 101 数据（国服统计），可换成 OP.GG（全球统计） |
| 极地大乱斗   | OP.GG，可关闭                                                     |
| 海克斯大乱斗 | 腾讯掌上英雄联盟，读不到时改用 ARAM.GG；兜底可关闭                |
| 斗魂竞技场   | OP.GG，可关闭                                                     |
| 其他模式     | 暂无推荐数据                                                      |

这些都在 **设置 › 通用 › 数据源** 里切换。OP.GG 的使用条款不允许自动抓取，ARAM.GG 也不希望程序批量读取它的数据文件，
介意的话可以关掉对应的一行：关掉大乱斗或斗魂竞技场的数据源后，这个模式的面板只显示“已在设置中关闭这个模式的数据源”，
已记住的符文和召唤师技能照常应用；关掉海克斯的兜底后，只用腾讯的数据。

这些都是第三方的公开统计，可能晚于版本更新；新版本的头几天没有数据时，用上一个版本的。读不到时面板会说明原因，并提供
**重试**。客户端不认识的装备和强化符文（例如其他版本的）不会显示。winer 只在你看着这个面板时读取这个英雄的数据，读到的
结果保留几个小时，不会预先读取其他英雄。在 **设置 › 通用** 关掉 **配装推荐** 后，面板隐藏，也不再联网读取。

### 写入装备方案

**出装** 页的 **写入装备方案** 把这些装备写成这个英雄的装备方案，名为「winer · 英雄名」，游戏内商店的装备方案里能找到。
选人时写入的方案本局就能用，游戏开始后再写入的要到下一局。自动写入和清除见[自动化](/guide/automation#装备方案)。
