# 工具与设置

## 工具

**工具** 页的几项操作都直接作用于客户端：

- **在线状态**：在线、离开、手机在线或隐身，效果和在客户端里切换相同；隐身时好友看到的是离线，手机在线时
  好友看到你在手机上在线。客户端自己设置的状态（例如游戏中）会显示为当前状态。
- **个性签名**：显示在你名字下方的一行字。
- **记住在线状态**：客户端启动时和每局结束后会把状态改回在线。打开后，winer 在连上客户端和每局结束后的一分钟内，
  把状态和个性签名改回你在这里选的。每次变化只改回一次；客户端连续三次立刻改回去时，winer 不再重试，并在动态里
  说明。默认关闭。
- **重启客户端界面**：只重启客户端的界面进程，登录状态和正在进行的游戏都不受影响。客户端界面卡住或插件更新后
  可以用它。

### 生涯背景

上方是当前的生涯背景。下面列出所有英雄的所有皮肤，已拥有和未拥有的都在内：可以按英雄名称、称号、英文名或皮肤
名称搜索，按英雄筛选，或者打开 **只看已拥有**。选中一款后点 **设为背景**。设置后 winer 会重新读取客户端的资料：
客户端可能不接受未拥有的皮肤，没有换成时页面上会直接说明，背景以客户端显示的为准。

### 挑战徽章与称号

资料卡上的三个挑战徽章从左到右排列，每个可以选一项已经达到等级的挑战，也可以清空；称号从你已经获得的称号里选。
点 **应用** 后，页面显示的是客户端实际接受的徽章和称号，没有完全接受时会提示。

### 段位伪装

打开后，好友在好友列表和资料卡里看到的是你选的段位：选择队列（单双排或灵活组排）、段位和分段，大师及以上没有分段。
它只改变好友看到的段位，你的真实段位、匹配和客户端里你自己的资料都不会变。客户端把段位改回去时，winer 会再改一次；
关闭开关后换回真实段位。默认关闭。

### 游戏设置备份

**备份** 把客户端里的常规设置（界面、镜头、声音、显示等）和按键设置存为一份备份，最多保留 10 份，超出时删除最旧的；
winer 不会自己备份。每份备份可以只恢复常规设置、只恢复按键设置，或者全部恢复，恢复后客户端立即保存。只能在房间或
客户端首页恢复，选人和对局中不能恢复。

要把备份带到另一台电脑，点 **在文件夹中显示** 找到备份文件并复制过去，再在那台电脑上用 **导入** 选择它。

## 设置

按 `Ctrl` + `,` 或点侧栏底部的 **设置** 打开。

### 外观

- **主题**：跟随系统、明亮、暗黑、石墨和海克斯。海克斯是仿照客户端的深蓝与金色。
- **强调色**、**信息密度**（标准或紧凑）、**字号**，以及 **减少动态效果**。

### 通用

- **语言**：简体中文或 English。
- **关闭窗口时留在托盘**：打开时点关闭按钮只是隐藏窗口，winer 继续在托盘里工作；关掉后点关闭会退出。左键点托盘
  图标打开窗口，右键菜单里可以开关自动接受和退出。
- **联网获取海克斯符文说明**：从 ARAM.GG 获取海克斯大乱斗符文的效果说明；关掉后只显示名称和图标。
- **开机自动启动**：登录 Windows 后在托盘里启动，不弹出窗口。

### 评级

评级方案、自定义档位、毒舌称号开关和评价依据，见[评级说明](/rating)。

### 关于

版本、当前的运行权限（管理员或普通用户）、日志目录和 **软件更新**。winer 启动后和运行期间会自动检查更新，这里可以
手动再查一次。

## 快捷键

| 按键             | 作用           |
| ---------------- | -------------- |
| `Ctrl` + `1`…`6` | 切换页面       |
| `Ctrl` + `,`     | 打开设置       |
| `Ctrl` + `B`     | 收起或展开侧栏 |
