# 工具与设置

## 工具

**工具** 页的几项操作都直接作用于客户端：

- **在线状态**：在线、离开、手机在线或隐身，效果和在客户端里切换相同；隐身时好友看到的是离线。手机在线时
  好友看到手机图标，文字却是客户端对这个状态的叫法“在线分组”。客户端自己设置的状态（例如游戏中）会显示为当前状态。
- **签名显示“手机在线”**：选中手机在线后出现的开关。打开后，没有个性签名时 winer 把签名设为“手机在线”，好友在
  好友列表和资料卡里看到带引号的“手机在线”；换成其他状态时撤下，你自己写的签名不受影响。打开记住在线状态时，它和
  状态一起恢复。默认关闭。
- **个性签名**：好友在你名字下方看到的一行字，客户端会给它加上引号。
- **记住在线状态**：客户端启动时和每局结束后会把状态改回在线。打开后，winer 在连上客户端和每局结束后的一分钟内，
  把状态和个性签名改回你在这里选的。每次变化只改回一次；客户端连续三次立刻改回去时，winer 不再重试，并在动态里
  说明。默认关闭。
- **重启客户端界面**：只重启客户端的界面进程，登录状态和正在进行的游戏都不受影响。客户端界面卡住或插件更新后
  可以用它。

### 我的备注

你给其他玩家写的[备注](/guide/history#我的备注)，最新的在前。可以按名字或内容搜索，点名字打开他的战绩，在那里修改；
每条右边的垃圾桶删除这条备注。

### 生涯背景

上方是当前的生涯背景。下面列出所有英雄的所有皮肤，已拥有和未拥有的都在内：可以按英雄名称、称号、英文名或皮肤
名称搜索，按英雄筛选，或者打开 **只看已拥有**。选中一款后点 **设为背景**。设置后 winer 会重新读取客户端的资料：
客户端可能不接受未拥有的皮肤，没有换成时页面上会直接说明，背景以客户端显示的为准。

### 挑战徽章、称号与旗帜

资料卡上的三个挑战徽章从左到右排列，每个可以选一项已经达到等级的挑战，也可以清空；称号从你已经获得的称号里选。
旗帜可以选客户端的默认旗帜或你拥有的旗帜，上赛季有排位段位时还可以选上赛季段位旗帜。点 **应用** 后，页面显示的是
客户端实际接受的徽章、称号和旗帜，没有完全接受时会提示。

### 段位伪装

打开后，好友在好友列表和资料卡里看到的是你选的段位：选择队列（单双排或灵活组排）、段位和分段，大师及以上没有分段。
它只改变好友看到的段位，你的真实段位、匹配和客户端里你自己的资料都不会变。客户端把段位改回去时，winer 会再改一次；
关闭开关后换回真实段位。默认关闭。

### 游戏设置备份

**备份** 把客户端里的常规设置（界面、镜头、声音、显示等）和按键设置存为一份备份，最多保留 10 份，超出时删除最旧的；
winer 不会自己备份。每份备份可以只恢复常规设置、只恢复按键设置，或者全部恢复，恢复后客户端立即保存。只能在房间或
客户端首页恢复，选人和对局中不能恢复。

要把备份带到另一台电脑，点 **在文件夹中显示** 找到备份文件并复制过去，再在那台电脑上用 **导入** 选择它。

## 设置

按 `Ctrl` + `,` 或点侧栏底部的 **设置** 打开。

### 外观

- **主题**：跟随系统、明亮、暗黑、石墨和海克斯。海克斯是仿照客户端的深蓝与金色。
- **强调色**、**信息密度**（标准或紧凑）、**字号**，以及 **减少动态效果**。

### 通用

- **语言**：简体中文或 English。
- **关闭窗口时留在托盘**：打开时点关闭按钮只是隐藏窗口，winer 继续在托盘里工作；关掉后点关闭会退出。左键点托盘
  图标打开窗口，右键菜单里可以开关自动接受和退出。
- **唤起 winer 的快捷键**：默认 `Alt` + `` ` ``（数字键 1 左边那个键），在任何地方按下都能显示或隐藏 winer：窗口在最前面时隐藏它，
  否则把它显示到最前面；游戏进行中唤出时，窗口会保持在游戏上方，直到再次隐藏或游戏结束。点 **更改快捷键** 后按下
  新的组合键，组合键要包含 `Ctrl`、`Alt` 或 `Win` 中的至少一个，按 `Esc` 取消；点旁边的 ✕ 关闭快捷键。组合键已被
  其他程序占用时，这一行会提示换一个。游戏需要使用无边框或窗口模式：独占全屏模式下，其他窗口一获得焦点，游戏就会
  最小化。
- **配装推荐**：在对局页显示[配装推荐](/guide/live#配装推荐)，数据来自腾讯掌上英雄联盟、OP.GG 和 ARAM.GG 的公开统计；
  关掉后面板隐藏，也不再联网读取。
- **选人推荐**：峡谷选人时推荐 3 个英雄，见[选人推荐](/guide/live#选人推荐)；只显示，不会替你选。
- **数据源**：每个模式的数据从哪里来，见[数据来源](/guide/live#数据来源)。
  - **召唤师峡谷的数据来源**：腾讯 101（国服统计）或 OP.GG（全球统计）。
  - **大乱斗的数据来源**、**斗魂竞技场的数据来源**：OP.GG 或关闭。
  - **海克斯大乱斗用 ARAM.GG 兜底**：腾讯没有数据时改用 ARAM.GG；关掉后只用腾讯的数据。
  - **联网获取海克斯符文说明**：从 ARAM.GG 获取海克斯大乱斗符文的效果说明；关掉后只显示名称和图标。
- **开机自动启动**：登录 Windows 后在托盘里启动，不弹出窗口。

### 评级

评级方案、自定义档位、毒舌称号开关和评价依据，见[评级说明](/rating)。

### 关于

版本、当前的运行权限（管理员或普通用户）、日志目录和 **软件更新**。winer 启动后和运行期间会自动检查更新，这里可以
手动再查一次。

**存储空间** 列出 winer 在本机保存的内容、各自的大小和上限：日志、窗口的网页视图数据、游戏设置备份、客户端增强组件、
设置与记住的配置、更新安装包和内存缓存，各自的位置见[数据与隐私](/privacy)。

- **清理缓存**：删除旧日志（正在写的那一个除外）、更新完成后留下的安装包和内存中的缓存；网页缓存在窗口打开期间
  正在使用，在下次启动 winer 时清除。游戏设置备份、设置和记住的符文与召唤师技能不会被删除。清理后，这一栏下方会说明
  删除了哪些内容、多大。
- 不清理也不会无限增长：日志只保留最近 7 天、合计最多 50 MB，内存中的缓存过期后定时释放，网页缓存最多 32 MB，
  更新安装包在下次启动时删除。

**诊断** 检查 winer 依赖的东西是否还正常：客户端和它的版本、winer 用到的客户端接口是否都还在、战绩服务器、
设置里用到的数据源、客户端插件、快捷键，以及最近一次检查更新的结果。点 **立即检查** 运行，每项最多等 10 秒；
**复制** 把结果复制成文字，方便反馈问题，文字里没有端口、路径和账号信息。诊断只读取，不会改动客户端。客户端更新后
第一次连上时，winer 会自动检查一次，有失败项就发一条通知。

## 快捷键

| 按键             | 作用           |
| ---------------- | -------------- |
| `Ctrl` + `1`…`6` | 切换页面       |
| `Ctrl` + `,`     | 打开设置       |
| `Ctrl` + `B`     | 收起或展开侧栏 |

`Alt` + `` ` ``（可以在 **设置 › 通用** 里更改）在任何地方都有效，包括游戏中：显示或隐藏 winer。其余快捷键
只在 winer 的窗口里有效。发送喊话的快捷键默认没有，在 **自动化 › 战力喊话** 里设置，同样在任何地方有效，见
[自动化](/guide/automation#战力喊话)。
