# 工具与设置

## 工具

**工具** 页的几项操作都直接作用于客户端：

- **在线状态**：在线、离开或隐身，效果和在客户端里切换相同；隐身时好友看到的是离线。客户端自己设置的状态
  （例如游戏中）会显示为当前状态。
- **个性签名**：显示在你名字下方的一行字。
- **重启客户端界面**：只重启客户端的界面进程，登录状态和正在进行的游戏都不受影响。客户端界面卡住或插件更新后
  可以用它。

## 设置

按 `Ctrl` + `,` 或点侧栏底部的 **设置** 打开。

### 外观

- **主题**：跟随系统、明亮、暗黑、石墨和海克斯。海克斯是仿照客户端的深蓝与金色。
- **强调色**、**信息密度**（标准或紧凑）、**字号**，以及 **减少动态效果**。

### 通用

- **语言**：简体中文或 English。
- **关闭窗口时留在托盘**：打开时点关闭按钮只是隐藏窗口，winer 继续在托盘里工作；关掉后点关闭会退出。左键点托盘
  图标打开窗口，右键菜单里可以开关自动接受和退出。
- **唤起 winer 的快捷键**：默认 `Ctrl` + `Shift` + `W`，在任何地方按下都能显示或隐藏 winer：窗口在最前面时隐藏它，
  否则把它显示到最前面；游戏进行中唤出时，窗口会保持在游戏上方，直到再次隐藏或游戏结束。点 **更改快捷键** 后按下
  新的组合键，组合键要包含 `Ctrl`、`Alt` 或 `Win` 中的至少一个，按 `Esc` 取消；点旁边的 ✕ 关闭快捷键。组合键已被
  其他程序占用时，这一行会提示换一个。游戏需要使用无边框或窗口模式：独占全屏模式下，其他窗口一获得焦点，游戏就会
  最小化。
- **联网获取海克斯符文说明**：从 ARAM.GG 获取海克斯大乱斗符文的效果说明；关掉后只显示名称和图标。
- **开机自动启动**：登录 Windows 后在托盘里启动，不弹出窗口。

### 评级

评级方案、自定义档位、毒舌称号开关和评价依据，见[评级说明](/rating)。

### 关于

版本、当前的运行权限（管理员或普通用户）、日志目录和 **软件更新**。winer 启动后和运行期间会自动检查更新，这里可以
手动再查一次。

## 快捷键

| 按键             | 作用           |
| ---------------- | -------------- |
| `Ctrl` + `1`…`6` | 切换页面       |
| `Ctrl` + `,`     | 打开设置       |
| `Ctrl` + `B`     | 收起或展开侧栏 |

`Ctrl` + `Shift` + `W`（可以在 **设置 › 通用** 里更改）在任何地方都有效，包括游戏中：显示或隐藏 winer。其余快捷键
只在 winer 的窗口里有效。
