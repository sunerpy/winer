# 快速开始

## 1. 启动并连接客户端

先登录英雄联盟客户端，再打开 winer。窗口底部的状态栏显示 **已连接** 和所在大区，概览页就会出现你的召唤师、
段位和近期状态。

国服客户端由 WeGame 以管理员身份启动，普通权限的程序读不到它。winer 发现后会自动请求以管理员身份重启，在 Windows
的用户账户控制提示里选 **是** 即可；取消了的话，窗口里的 **以管理员身份重启** 可以再试一次。

连上客户端后，winer 会自动装好自带的 Pengu Loader 和客户端插件。第一次激活 Pengu Loader 需要一次管理员权限：
winer 不是以管理员身份运行时，会请求以管理员身份重启，选 **是** 即可，见[客户端增强](/guide/client#第一次激活需要管理员权限)。

## 2. 进入英雄选择

进入英雄选择后，**对局** 页会列出我方每位玩家：段位、近 20 场的胜率和 KDA、最近每一局的英雄和战绩，以及按近期
战力排出的档位、称号和一句评语。地图分红蓝方时，标题会写明我方是红色方还是蓝色方。点任何一位玩家，就能打开
他的完整战绩。

页面下方的 **战力喊话** 是按档位排好的聊天内容：点 **发送到队伍** 发给队友，点 **仅自己可见** 只在自己的聊天框
里显示。想每局自动发送，在 **自动化 › 战力喊话** 打开 **进入选人后自动发送**。

## 3. 查战绩

**战绩** 页默认显示你自己的战绩。在搜索框输入 `名称#编号` 可以查任何人。每一局都标出 MVP、SVP 和本局成就，
点开就是这局的完整记分板。

## 4. 打开需要的自动化

**自动化** 页里每一项都可以单独开关，并选择在哪些模式里生效，例如只在排位里自动禁用英雄。顶部的
**按模式查看** 会告诉你某个模式里实际会发生什么。

## 5. 在客户端里看队友战绩

客户端插件装好后，客户端自己的选人界面里每位队友名字下方会多出一行：档位与称号、段位、近期胜率和 KDA。要关掉它，
在 **客户端增强** 页点 **停用客户端增强**。见[客户端增强](/guide/client)。
