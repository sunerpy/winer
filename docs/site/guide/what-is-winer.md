# winer 是什么

winer 是英雄联盟客户端的助手，只做 Windows 版，在腾讯客户端（国服）上实测。它读的是客户端自己在本机开放的
接口（LCU），不修改游戏文件，也不读取游戏进程的内存。

它由两部分组成：

- **桌面窗口**：概览、对局分析、战绩、自动化和工具，客户端开着的时候随时可用，关掉窗口后留在托盘。
- **客户端插件**：经由 [Pengu Loader](https://github.com/PenguLoader/PenguLoader) 装进客户端页面，在选人界面里
  直接显示队友的战绩、评级和称号，并让大乱斗的备选席英雄点击即换。winer 自带 Pengu Loader，连上客户端时自动装好，
  不想要时可以停用。

## 它能做什么

- **对局分析**：进入英雄选择后，逐行列出双方每位玩家的段位、近期胜率、KDA 和最近十来局，标出红蓝方和开黑
  的队友，按近期战力给每人一个档位、一个称号和一句评语。见[对局分析与喊话](/guide/live)。
- **战绩**：按名称查任何人的战绩，分页翻完整个历史，按模式筛选；每局标出 MVP、SVP 和成就徽章，展开就是
  带单局评分的记分板。见[战绩与成就](/guide/history)。
- **自动化**：自动接受对局，按分路自动选择和禁用英雄，进入选人后自动喊话，对局结束自动回到房间，大乱斗里
  自动换心愿英雄，每一项都可以限定在哪些模式里生效。见[自动化](/guide/automation)。
- **工具**：切换在线状态（在线、离开、隐身）、改个性签名、重启客户端界面。

评分和评级是 winer 自己的公式，规则全部写在[评级说明](/rating)里。

## 它不做什么

- 不提供 macOS 和 Linux 版本。
- 不读取游戏进程的内存，不修改游戏文件，不注入游戏本身；插件只运行在客户端的界面页面里。
- 不收集使用数据，也不需要账号。它会连接哪些地址，见[数据与隐私](/privacy)。

winer 不是 Riot Games 或腾讯的产品，也未获其认可。
