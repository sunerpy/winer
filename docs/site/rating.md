# 评级说明

winer 在三个地方评价玩家：

- **对局分析**：选人和对局中，按近期战力给每位玩家一个档位，附带称号和一句评语。
- **喊话**：把同样的档位、称号和评语写进聊天。
- **战绩记分板**：给每一局里的每个人打单局评分和评级，并标出 MVP、SVP 和单局称号。

公式都是 winer 自己的，写在 [`rating.rs`](https://github.com/sunerpy/winer/blob/main/crates/core/src/rating.rs)
和 [`tiers.ts`](https://github.com/sunerpy/winer/blob/main/app/frontend/src/lib/tiers.ts) 里，不复刻客户端、WeGame
或其他工具的评分。评级方案和称号开关在 **设置 › 评级**。

## 近期战力（0–10）

- 从客户端列出的最近对局里，由新到旧取 20 场和其他玩家打的对局。自定义对局（包括训练模式）和人机对局不计入，
  也不占这 20 场。哪些是人机对局，以客户端自己的队列目录为准：类别为人机的队列，以及类型写明对手是电脑的队列
  （比如末日人工智能）；新手教程也算。腾讯客户端只列出最近 20 到 30 场，这类对局多时，实际场次会少于 20。
- 这 20 场里的重开局只显示，不计入胜负、KDA、连胜和战力。
- 胜率与 KDA 各占一半：`10 × (0.5 × 胜率 + 0.5 × (1 − e^(−KDA/3)))`。KDA 3.0 折合 0.63，6.0 折合
  0.86。
- 场次少时向 5.0 收拢：`战力 = c × 原始分 + (1 − c) × 5.0`，其中 `c = 场次 / (场次 + 5)`。所以一两场
  的好成绩排不到前面。

参考：二十场胜率五成、KDA 3，大约是 5.5；胜率五成、KDA 4.3，大约是 6.0。

### 只看一位玩家时

战绩页的玩家资料里也显示档位、称号和评语，算法和选人时相同。只是本队排名需要队友：一个人和自己排名，永远落在
中间那一档。所以只看一位玩家时，先按峡谷八档的固定分段定级，再把八档按顺序均分到当前方案的各档上，分法和本队
排名分档相同：第 g 级（S+ 为 0）落在 `(g + ½) / 8 × 档数` 所在的档。默认的峡谷五档是这样对应的：

| 峡谷八档 | S+、S      | A          | B、C       | D        | E、F     |
| -------- | ---------- | ---------- | ---------- | -------- | -------- |
| 峡谷五档 | 峡谷通天代 | 人形防御塔 | 峡谷公务员 | 移动眼位 | 纯正牛马 |

选了峡谷八档时，档位就是这个评级，和选人时一样。其他方案下，同一位玩家在选人时的档位还要看同队的其他人，
和战绩页可能不同。

## 喊话

每位队友一行，从档位最好的开始。**自动化 › 战力喊话** 里的 **喊话样式** 决定默认格式：

- **丰富**（默认）：档位前加表情，写上称号和档位评语。

  ```text
  {emoji}{standing}：{seat} {name}，近{games}场胜率{winRate}，KDA {kda}，战力{score}{title}{quip}
  ```

  ```text
  📢【蓝色方】winer 战绩鉴定
  👑 峡谷通天代：1L 暗夜里的光，近20场胜率60%，KDA 4.1，战力7.4「版本答案」，对面五个人准备举报代练
  👌 峡谷公务员：2L 峡谷清道夫，近20场胜率50%，KDA 2.9，战力5.2「正常发挥」，按时上班，准时打卡
  💀 纯正牛马：5L 眼位守护者，近20场胜率40%，KDA 2.0，战力3.9「黑白电视机资深会员」，勤勤恳恳地给对面创造游戏体验
  ```

- **精简**：每人一行，同样几项按同样的顺序，名称放最后，几行上下一对就能比出高低。

  ```text
  {seat} {standing}｜胜率{winRate}｜KDA {kda}｜战力{score}｜{name}
  ```

  ```text
  【蓝色方】winer 战绩鉴定
  1L 峡谷通天代｜胜率60%｜KDA 4.1｜战力7.4｜暗夜里的光
  2L 峡谷公务员｜胜率50%｜KDA 2.9｜战力5.2｜峡谷清道夫
  5L 纯正牛马｜胜率40%｜KDA 2.0｜战力3.9｜眼位守护者
  ```

`{emoji}` 是档位的表情：最好的一档 👑，中游以上的其他档 🔥，中游 👌，中游以下 😅，最差的一档 💀；峡谷八档里
S+ 是 👑，S、A 是 🔥，B、C 是 👌，D、E 是 😅，F 是 💀。表情只在客户端的聊天里显示，游戏里输入的喊话不带表情。

- 第一行写我方所在的红蓝方和「winer 战绩鉴定」，后面接开场白（如果填了）；丰富样式在最前面加 📢。
- `{seat}` 是这位队友在选人界面我方列表里的位置，从上往下数，写作 1L 到 5L（英文界面是 P1 到 P5）。每行写位置和
  名称，不写英雄：选人时英雄还会变，位置不会。
- `{title}` 是近期称号，没有称号时留空；`{quip}` 是档位评语。内置方案的每个档位都有评语，峡谷五档每档
  三句，按玩家和对局挑一句：同一次选人里不变，换一局多半会换。自定义名称没有评语。
- 每行内容和开场白在 **自动化 › 喊话** 里改，可用的占位符：`{emoji}` `{standing}` `{seat}` `{name}` `{champion}`
  `{games}` `{winRate}` `{kda}` `{score}` `{title}` `{quip}`。自己写了格式时以它为准，两种样式都一样。自己写的格式里
  仍然可以用 `{champion}`，填的是发送时这位队友选中或亮出的英雄。

### 游戏中的喊话

游戏中按发送喊话的快捷键（需要打开 **游戏内发送**）默认只说敌方的两个人，评级规则与队友相同：

- **提防的敌人**：评级高于中游的敌人里最高的一位，同档时取近期战力更高的。
- **可以针对的敌人**：评级低于中游的敌人里最低的一位，同档时取近期战力更低的。

按本队排名的方案以中间一档为中游：五档时前两档高于中游、后两档低于中游，三档时只有第一档和最后一档算。峡谷八档里
S+、S、A 高于中游，D、E、F 低于中游，B 和 C 是普通水平。没有这样的敌人时那一行不发。在 **自动化 › 战力喊话** 也可以
改为说我方或双方，我方每位队友一行，档位与选人时相同。默认格式：

```text
小心 {champion}：{standing}，近{games}场胜率{winRate}，KDA {kda}{title}
对面 {champion}：{standing}，近{games}场胜率{winRate}，可以多抓
{standing}：{champion}，近{games}场胜率{winRate}，KDA {kda}，战力{score}{title}{quip}
```

前两行说敌方，第三行是我方每位队友的格式；选了精简样式时，我方每行是
`{standing} {champion}｜胜率{winRate}｜KDA {kda}｜战力{score}`。敌方的第一行写敌方所在的红蓝方和「winer 战绩鉴定」，例如「【敌方·红色方】winer
战绩鉴定」；我方的写「【我方·蓝色方】winer 战绩鉴定」。游戏里的英雄已经定下，认人看的也是英雄，所以默认格式只写英雄，
读不到英雄时改用名称；`{name}` 和 `{seat}` 仍然可用，`{seat}` 是这位玩家在本队列表里的位置。

### 近期称号（对局分析与喊话）

至少要有 5 场战绩。称号和它旁边的档位同一个方向：档位在中游以上的只会得到夸的称号，中游以下的才会得到损的，
中游的只看打法。中游的划分和上面游戏中喊话的一样。

场均击杀、死亡和助攻都和同一模式的平均水平比：大乱斗一局的击杀和死亡大约是召唤师峡谷的两倍，助攻三倍多，
同样死 10 次，在峡谷是死得多，在大乱斗只是平常。平均水平取自拟合单局评分时用的那批 WeGame 对局：召唤师峡谷
每人每局 5.1 / 5.2 / 7.5，两种大乱斗 11.1 / 11.1 / 25.6。下表的「×1.3」指这一项是平均水平的 1.3 倍；斗魂竞技场等没有
平均水平的模式不参与这几项比较，至少要有 5 局能比时才看。

按顺序取第一条符合的；本档没有符合的，再看「各档通用」；都不符合时用最后一行。

## 单局评分（0–10）与评级

每一项都和本局所有玩家的平均值相比，最多按三倍计；本局平均不到 1 的项目不计入（比如大乱斗里的视野）。

WeGame 没有公开它的评分方法。winer 的权重是拿 WeGame 打过分的对局拟合出来的，目标是让 winer 评出的 MVP、
SVP 尽量和 WeGame 一致：在 126 局召唤师峡谷（排位与匹配）里，MVP 有 85%、SVP 有 83% 与 WeGame 相同；在
139 局海克斯大乱斗里分别是 80% 和 73%。原先所有模式共用一套权重时，这两组数字是 68% / 58% 和 68% / 56%。
一般认为 WeGame 会拿你和同英雄的玩家比较，单看一局的数据做不到，剩下的差距主要在这里。

两类模式的权重不同：有兵线的地图要算补刀和视野；大乱斗里没人补刀，经济更能说明问题。

| 项目                                  | 召唤师峡谷 | 大乱斗、海克斯大乱斗 |
| ------------------------------------- | ---------- | -------------------- |
| 经济                                  | 0.36       | 0.34                 |
| 存活（`(平均死亡 + 1) / (死亡 + 1)`） | 0.19       | 0.22                 |
| 击杀                                  | 0.12       | 0.09                 |
| 助攻                                  | 0.09       | 0.09                 |
| 对英雄伤害                            | 0.09       | 0.10                 |
| 承伤                                  | 0.05       | 0.09                 |
| 补刀（小兵和野怪）                    | 0.06       | —                    |
| 视野                                  | 0.04       | —                    |
| 控制时长                              | —          | 0.01                 |

本分。所以大乱斗按英雄在客户端里的第一个定位，各用一套权重计入，再统一按上表一列的总和折算，普通水平的
玩家不论定位都在 6.0 上下：

| 定位 | 击杀 | 助攻 | 对英雄伤害 | 承伤 | 经济 | 控制时长 | 存活 |
| ---- | ---- | ---- | ---------- | ---- | ---- | -------- | ---- |

| 辅助 | 0.14 | 0.09 | 0.13       | 0.10 | 0.35 | —        | 0.20 |
| 法师 | 0.10 | 0.09 | 0.09       | 0.10 | 0.34 | —        | 0.21 |
| 刺客 | 0.07 | 0.08 | 0.09       | 0.09 | 0.34 | 0.02     | 0.22 |
| 射手 | 0.07 | 0.08 | 0.09       | 0.11 | 0.33 | 0.02     | 0.22 |
| 战士 | 0.08 | 0.08 | 0.10       | 0.08 | 0.34 | 0.01     | 0.22 |

客户端没有给出定位的英雄用上表的大乱斗一列。召唤师峡谷试过同样的做法，没有带来能看出的提升，所以不分定位。
斗魂竞技场、无限火力等其他模式用召唤师峡谷这一列。

把加权平均 x（相当于几个平均水平的玩家）代入 `10 / (1 + e^(−4 × (x − c)))`，其中
`c = 1 − ln(1.5) / 4`，这样恰好平均水平的玩家得 6.0。1.25 倍平均得 8.0，1.5 倍得 9.2，0.75 倍得 3.6，
一半得 1.7，最高 10 分。

- **MVP**：胜方评分最高的人；**SVP**：败方评分最高的人。需要有一方胜、一方负，同分时算先列出的那个。
  战绩列表里，MVP、SVP 标在英雄头像的左上角。
- **单局评级**：

  | 评级 | S+    | S     | A     | B     | C     | D     | E     | F     |
  | ---- | ----- | ----- | ----- | ----- | ----- | ----- | ----- | ----- |
  | 评分 | ≥ 9.0 | ≥ 8.0 | ≥ 7.0 | ≥ 6.0 | ≥ 5.0 | ≥ 4.0 | ≥ 3.0 | < 3.0 |

  本局平均水平是 B。

- 重开局不评分，也不评 MVP、SVP。

## 成就徽章

战绩列表和记分板还会给每个人标出本局的成就，规则如下：

| 徽章                                                 | 条件                                                           |
| ---------------------------------------------------- | -------------------------------------------------------------- |
| 双杀、三杀、四杀、五杀                               | 本局最多的一次多杀，只标最高的那一个                           |
| 超神                                                 | 连续击杀 8 人以上没有阵亡                                      |
| 一血                                                 | 拿下本局第一个击杀                                             |
| 杀人、助攻、金币、补兵最多，输出、承伤最高，推塔最多 | 全场这一项最多；并列时都算，全场一样多（比如都是 0）时谁都不算 |
