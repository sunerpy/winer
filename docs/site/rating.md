# 评级说明

winer 在三个地方评价玩家：

- **对局分析**：选人和对局中，按近期战力给每位玩家一个档位，附带称号和一句评语。
- **喊话**：把同样的档位、称号和评语写进聊天。
- **战绩记分板**：给每一局里的每个人打单局评分和评级，并标出 MVP、SVP 和单局称号。

公式都是 winer 自己的，写在 [`rating.rs`](https://github.com/sunerpy/winer/blob/main/crates/core/src/rating.rs)
和 [`tiers.ts`](https://github.com/sunerpy/winer/blob/main/app/frontend/src/lib/tiers.ts) 里，不复刻客户端、WeGame
或其他工具的评分。评级方案和称号开关在 **设置 › 评级**。

## 近期战力（0–10）

- 取客户端给出的最近 20 场，自定义对局不计入，所以有自定义局时实际场次会少于 20。
- 胜率与 KDA 各占一半：`10 × (0.5 × 胜率 + 0.5 × (1 − e^(−KDA/3)))`。KDA 3.0 折合 0.63，6.0 折合
  0.86。
- 场次少时向 5.0 收拢：`战力 = c × 原始分 + (1 − c) × 5.0`，其中 `c = 场次 / (场次 + 5)`。所以一两场
  的好成绩排不到前面。

参考：二十场胜率五成、KDA 3，大约是 5.5；胜率五成、KDA 4.3，大约是 6.0。

读取失败）不评档。

## 喊话

默认每位队友一行：

```text
{standing}：{seat} {name} 近{games}场胜率{winRate} KDA {kda} 评分{score}{title}{quip}
```

例如：

```text
【蓝色方】winer 战绩鉴定
峡谷通天代：1L 暗夜里的光 近20场胜率60% KDA 4.1 评分7.4「版本答案」，对面五个人准备举报代练
峡谷公务员：2L 峡谷清道夫 近20场胜率50% KDA 2.9 评分5.2，按时上班，准时打卡
```

- 第一行写我方所在的红蓝方和「winer 战绩鉴定」，后面接开场白（如果填了）。
- `{seat}` 是这位队友在选人界面我方列表里的位置，从上往下数，写作 1L 到 5L（英文界面是 P1 到 P5）。每行写位置和
  名称，不写英雄：选人时英雄还会变，位置不会。
- `{title}` 是近期称号，没有称号时留空；`{quip}` 是档位评语。内置方案的每个档位都有评语，峡谷五档每档
  三句，按玩家和对局挑一句：同一次选人里不变，换一局多半会换。自定义名称没有评语。
- 每行内容和开场白在 **自动化 › 喊话** 里改，可用的占位符：`{standing}` `{seat}` `{name}` `{champion}`
  `{games}` `{winRate}` `{kda}` `{score}` `{title}` `{quip}`。自己写的格式里仍然可以用 `{champion}`，填的是发送时
  这位队友选中或亮出的英雄。

## 毒舌称号

**设置 › 评级 › 毒舌称号** 关掉后，下面两类称号都不再显示，喊话里的 `{title}` 也留空。

至少要有 5 场战绩，按顺序取第一条符合的：

| --------------------------------- | ------------------ |
| 三连胜及以上                      | 版本答案           |
| 三连败及以上                      | 排位慈善家         |
| 场均击杀 ≤ 2，场均死亡 ≥ 7        | 电竞菩萨           |
| KDA ≥ 6                           | 峡谷永生者         |
| 场均击杀 ≥ 8，场均死亡 ≥ 7        | 一换一专业户       |
| 场均死亡 ≥ 8                      | 黑白电视机资深会员 |
| 场均助攻 ≥ 12，且不少于击杀的两倍 | 峡谷慈善家         |

| 下路核心，死亡 ≥ 9                                           | AD去质器           |
| 输了，伤害占比 ≥ 30%                                         | 院长               |
| 赢了，伤害占比 < 12%                                         | 冠军拼图           |
| 击杀和死亡都 ≥ 10                                            | 一换一专业户       |
| 死亡 ≥ 10                                                    | 黑白电视机资深会员 |

## 单局评分（0–10）与评级

每一项都和本局所有玩家的平均值相比，最多按三倍计；本局平均不到 1 的项目不计入（比如大乱斗里的视野）。

| 项目                                  | 权重 |
| ------------------------------------- | ---- |
| 击杀参与（击杀 + 0.7 × 助攻）         | 0.30 |
| 对英雄伤害                            | 0.25 |
| 承伤（含减免）                        | 0.12 |
| 经济                                  | 0.10 |
| 推进伤害                              | 0.08 |
| 视野                                  | 0.05 |
| 控制时长                              | 0.05 |
| 存活（`(平均死亡 + 1) / (死亡 + 1)`） | 0.05 |

把加权平均 x（相当于几个平均水平的玩家）代入 `10 / (1 + e^(−4 × (x − c)))`，其中
`c = 1 − ln(1.5) / 4`，这样恰好平均水平的玩家得 6.0。1.25 倍平均得 8.0，1.5 倍得 9.2，0.75 倍得 3.6，
一半得 1.7，最高 10 分。

- **MVP**：胜方评分最高的人；**SVP**：败方评分最高的人。需要有一方胜、一方负，同分时算先列出的那个。
  战绩列表里，MVP、SVP 标在英雄头像的左上角。
- **单局评级**：

  | 评级 | S+    | S     | A     | B     | C     | D     | E     | F     |
  | ---- | ----- | ----- | ----- | ----- | ----- | ----- | ----- | ----- |
  | 评分 | ≥ 9.0 | ≥ 8.0 | ≥ 7.0 | ≥ 6.0 | ≥ 5.0 | ≥ 4.0 | ≥ 3.0 | < 3.0 |

  本局平均水平是 B。

- 重开局不评分，也不评 MVP、SVP。

## 成就徽章

战绩列表和记分板还会给每个人标出本局的成就，规则如下：

| 徽章                                                 | 条件                                                           |
| ---------------------------------------------------- | -------------------------------------------------------------- |
| 双杀、三杀、四杀、五杀                               | 本局最多的一次多杀，只标最高的那一个                           |
| 超神                                                 | 连续击杀 8 人以上没有阵亡                                      |
| 一血                                                 | 拿下本局第一个击杀                                             |
| 杀人、助攻、金币、补兵最多，输出、承伤最高，推塔最多 | 全场这一项最多；并列时都算，全场一样多（比如都是 0）时谁都不算 |
| 逃兵                                                 | 本局被系统判定挂机或提前离开                                   |

重开局只保留「逃兵」。「逃兵」来自战绩服务器的标记，客户端本地的 20 场记录里没有这一项。全场最多的几项
需要整局十个人的数据，只在能读到整局时标出。
